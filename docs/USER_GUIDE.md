# Tally 新用户操作指南

**适用版本：v0.7.5**
**适用对象：** 第一次使用 Tally 的交易者
**读完你能做到：** 连上 MT5、完成第一笔模拟交易、管理持仓与风控、复盘交易并查看统计。

> Tally 是一个运行在本机的 MT5 图表交易终端：你在 TradingView 风格的图表上画线、拖价格、下单，订单经本地网关交给本机 MetaTrader 5 执行。
> 本文只讲**怎么操作**，不构成投资建议。任何实盘操作前，请先在模拟账户完整走通一遍。

## 1. 一分钟了解 Tally

### 1.1 它是什么

| Tally 会做 | Tally 不会做 |
|---|---|
| 显示 MT5 的真实品种、报价和多周期 K 线 | 自己连接券商服务器 |
| 在图上画线下单、拖动止损止盈 | 代替 MT5 保存持仓 |
| 通过本地网关把订单交给本机 MT5 | 替你决定交易方向 |
| 记录交易日志、截图、统计和执行质量 | 把交易数据上传到云端 |
| 用历史行情做模拟复盘 | 提供投资建议或收益承诺 |

Tally 是 MT5 的「图形操作台」：行情和执行都来自你电脑上已经登录的 MetaTrader 5。关掉 MT5，Tally 就没有行情，也不能下单。

### 1.2 数据放在哪里

所有交易库、截图、审计日志、导出和备份都只保存在这台电脑上：

```text
%LOCALAPPDATA%\MyTrade\gateway\
├─ config.json     账户与风控配置
├─ data\           交易库、MT5 凭据（DPAPI 加密）、截图
├─ audit\          按天写的 JSONL 审计日志
├─ exports\        导出的 CSV / JSON
├─ backups\        整库备份 zip
└─ gateway.log     网关日志
```

具体路径可以在「设置 → 数据与备份 → 本机数据目录」里查看，桌面版可以直接点「打开导出目录 / 打开备份目录」。

### 1.3 三种交易模式

| 模式 | 顶部显示 | 能做什么 | 什么时候用 |
|---|---|---|---|
| 只读 | 只读 | 看行情、看图、看持仓和日志；下单按钮不可用 | 默认状态；分析行情时 |
| 模拟可交易 | 模拟可交易 | 向模拟账户发单 | 第一次上手、练习流程 |
| 实盘交易 | 实盘交易 | 向实盘账户发单，真实资金 | 模拟流程完全走通之后 |

实盘模式不是点一下就能开：除了切模式，还要在「设置 → 交易与风控」打开实盘开关，并在 MT5 里打开 Algo Trading。具体见 [13. 实盘前检查清单](#13-实盘前检查清单)。

## 2. 安装与首次启动

### 2.1 系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11 |
| 交易终端 | MetaTrader 5，已安装并登录账户 |
| 桌面版 | 无需另装 Python 或 Node，安装包已带网关 |
| 源码运行 | Python 3.10+、`MetaTrader5` 包、Node.js 20+；打包桌面版还需要 Rust |

### 2.2 安装桌面版

1. 下载并运行 `Tally_x.y.z_x64-setup.exe`（或 `.msi`）。
2. 安装包未签名，Windows 可能弹出 SmartScreen：选「更多信息 → 仍要运行」。
3. 安装完成后从开始菜单启动 Tally。网关会作为后台程序自动拉起，**不需要另开终端跑 Python**。

### 2.3 第一次启动会看到什么

启动页按三个阶段提示，连上并拿到第一份行情后自动淡出：

| 阶段 | 页面提示 | 一直停在这里时怎么办 |
|---|---|---|
| 本地网关 | 正在启动本地网关… | 等 6 秒以上仍未连上，看提示里的 `gateway.log` 最近一行 |
| MT5 终端 | 正在连接 MT5 终端… | 确认 MT5 已启动并登录；首次启动通常要十几秒 |
| 账户同步 | 正在同步账户与持仓… | 读取品种、余额和仓位，一般很快 |

终端长时间连不上时，启动页会在 10 秒后放行到应用内，错误继续显示在底部状态栏，不会一直卡住。

### 2.4 连接你的 MT5 账户

有两种方式，任选其一：

**方式 A：在 MT5 里手动登录（最简单）**

1. 启动 MetaTrader 5，用你的账户登录。
2. 启动 Tally，等待启动页走完。
3. 顶部账户菜单显示登录号和服务器，状态栏显示「已连接」。

**方式 B：在 Tally 里保存密码，自动登录**

1. 打开「设置 → MT5 账户」。
2. 点「添加账户」，填写：
   - 账户名称（只用于界面显示，例如「模拟 A」）
   - 登录号
   - 服务器（必须和 MT5 登录窗口里完全一致）
   - `terminal64.exe` 的完整路径
   - 密码（留空则使用终端已登录的账户）
3. 保存后点列表里的「使用」。网关会连上终端，再用这组凭据登录并校验账户号。
4. 密码用 Windows DPAPI 加密保存在本机，只有当前 Windows 用户能解密，不会写入 `config.json`，也不会回发到界面。

> 电脑上同时开着多个 MT5 时，**必须**在账户里指定 `terminal64.exe` 路径，否则可能连到最近用过的那个终端。

### 2.5 打开 MT5 的 Algo Trading

第一次切到可交易模式前，在 MT5 顶部工具栏点击 **Algo Trading（算法交易 / 自动交易）**，图标变绿。没打开时网关会拒绝下单，状态栏会显示「Algo Trading 未开启」。

### 2.6 从源码运行（开发者）

```bash
npm install
pip install -r gateway/requirements.txt
npm run gateway   # 终端 1：本地网关
npm run dev       # 终端 2：Vite 开发页，打开 http://localhost:5173
```

桌面开发版：

```bash
npm run tauri:dev
```

打包安装包：

```bash
npm run gateway:setup   # 首次打包前执行一次
npm run tauri:build
```

> 源码运行时，`public/charting_library/` 必须存在（TradingView 官方库，已 gitignore，不随仓库分发）。缺少时图表会空白并提示「Charting Library 未加载」。

### 2.7 升级

桌面版启动约 6 秒后会自动检查新版本，有更新时右下角提示，可以「立即更新」「稍后」或「忽略此版本」。也可以点「设置 → 更新 → 检查更新」。更新包带签名校验，签名不匹配不会安装。

## 3. 界面总览

### 3.1 左侧导航

| 分组 | 入口 | 作用 |
|---|---|---|
| 工作台 | **概览** | 账户、今日风控、最近交易、例行/门禁/复盘入口 |
| 工作台 | **交易台** | 图表、画线下单、下单票、持仓/挂单/自选 |
| 复盘 | **历史复盘** | 用历史行情模拟交易，生成复盘报告 |
| 记录 | **交易记录** | 交易列表（交易日志）与盈亏日历 |
| 分析 | **分析** | 报表（统计报表 + 执行质量）、复盘（绩效趋势 + 深度分析） |
| 纪律 | **纪律** | 策略手册、例行清单、错过机会 |
| 底部 | **设置** | 外观、风控、账户、告警、数据与更新 |

另外两个页面不在左侧导航里：

- **过程评分**：从「概览」的过程评分卡片进入，或按 `Ctrl/Cmd+K` 搜索「过程评分」。
- **审计日志**：在「设置 → 诊断」内查看，或按 `Ctrl/Cmd+K` 搜索「审计日志」。

左侧底部还有：

- **隐私模式**：打开后，复盘与报表页的金额显示为 `••••`；交易台不受影响，避免影响下单判断。
- **连接状态**：网关、MT5 终端是否在线，当前交易状态和版本号。

### 3.2 交易台布局

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：布局｜Bid/Ask/点差｜告警｜日历｜账户｜余额｜风控｜急停｜模式 │
├───────────────────────────────────────────┬──────────────────┤
│                                           │  下单票          │
│              图表区                       │  （方向/类型/    │
│       （单图或 2×2 / 多图布局）           │   手数/风险/模板）│
│                                           ├──────────────────┤
│                                           │ 持仓｜挂单｜自选  │
├───────────────────────────────────────────┴──────────────────┤
│ 状态栏：网关｜终端｜账户｜风控提示｜模式｜延迟｜版本            │
└──────────────────────────────────────────────────────────────┘
```

### 3.3 顶栏

从左到右：

- **布局**：单图到 6 图；多图可同步品种、周期、十字线和可视区间。
- **Bid / Ask / 点差**：当前品种的实时报价。
- **告警**：打开右侧价格告警面板，角标是启用中的告警数量。
- **日历**：打开右侧财经日历面板。
- **账户菜单**：显示当前账户名称、登录号和连接状态，可切换账户。
- **余额 / 净值**：当前账户的实时余额与净值。
- **风控胶囊**：今日盈亏、当日亏损上限、剩余额度。悬停可看今日开仓次数、连亏次数和拦截原因；颜色会从绿变琥珀再变红。
- **急停**：点两次「急停」会平掉全部仓位、撤销全部挂单并停机，之后所有新开仓都会被拒绝；按钮变成「恢复交易」，再点一次解除。停机状态存在数据库里，重启网关仍然生效。
- **模式**：只读 / 模拟可交易 / 实盘交易。实盘账户在未打开实盘开关时是锁定的。
- **连接状态**：已连接 / 等待终端 / 未连接。

### 3.4 状态栏

底部状态栏显示：网关连接、MT5 终端与 build、账户登录号@服务器、当前风控拦截原因、交易模式、Algo Trading 是否开启、通信延迟和应用版本。

### 3.5 命令面板与快捷键

按 `Ctrl/Cmd+K` 打开命令面板：输入关键词过滤，`↑` `↓` 选择，`Enter` 执行，`Esc` 关闭。可以跳页、切主题、打开日历、导出日志、创建备份、检查更新。

常用快捷键：

| 按键 | 作用 |
|---|---|
| `B` | 建立买入市价草稿（只填入票面，仍需确认） |
| `S` | 建立卖出市价草稿 |
| `Esc` | 关闭弹窗、取消确认窗或清除当前划线草稿 |
| `Ctrl/Cmd+K` | 打开命令面板 |
| `Shift` + 拖动价格线 | 价格吸附到整数点位（FX 10 个点、黄金 0.1、日元 0.01） |

输入框里按这些键不会抢占输入。

## 4. 第一笔模拟交易（分步）

开始前先过一遍这张表：

| 检查项 | 应该看到 |
|---|---|
| MT5 已启动并登录 | MT5 界面正常显示行情 |
| Algo Trading 已打开 | MT5 工具栏按钮是绿色 |
| Tally 已连接 | 顶栏右下角「已连接」 |
| 当前是模拟账户 | 顶部账户菜单显示模拟账户 |
| 当前是只读模式 | 顶栏右侧显示「只读」 |

### 第 1 步：进入交易台，选品种和周期

1. 左侧点「交易台」。
2. 在图表左上角选择品种（如 `EURUSD`）和周期（如 `15m`）。
3. 右侧「自选」里点一行也能切换品种；多图时先点目标格子再切换。

### 第 2 步：切到模拟可交易

1. 确认 MT5 的 Algo Trading 已打开。
2. 点顶栏右侧的「只读」按钮。
3. 确认后按钮变成「模拟可交易」，状态栏同步显示。

> 实盘账户这一步会变成「实盘交易」，且需要先在设置里打开实盘开关，见第 13 章。

### 第 3 步：设置这一单的风险

在右侧下单票的「风险开仓」里选一种：

- **固定金额**：例如每单最多亏 100 USD。
- **余额 %**：例如每次风险为余额的 0.5%。

保持「自动手数」开启。设置止损后，手数会按「止损距离 × 每点价值」自动算出；拖动止损线会立即重算。

> 手动改手数会切回「手动手数」，下次改止损不会再自动算。想恢复自动，重新点一下「自动手数」。

### 第 4 步：在图上画线或填票面

两种方式可以混用：

1. **画线下单**：点下单票右上角「画线下单」，图表上出现一条可拖动的委托线；在图上点击目标价位也行。
2. **直接填**：在票面填入场价、止损、止盈。

图上的委托线右缘有 `TP` / `SL` 徽标：按住徽标向上或向下拖动，虚线跟着指针走，松手才写入草稿；只点一下不会生成。生成后右边缘的价格小块可以继续按住上下拖动。

### 第 5 步：看预览

下单票下方会实时显示：

- 保证金
- 风险金额和风险 %
- 盈亏比（R:R）
- 点差
- 黄色警告（如有）

如果风险、手数或止损距离不合理，网关会在这里给出提示。先解决警告再下单。

### 第 6 步：确认并发送

1. 点票面底部的「买入 x.xx / 卖出 x.xx」按钮。
2. 弹出「确认下单」窗，核对方向、类型、手数、价格、止损、止盈、预估风险和策略标签。
3. 点确认。订单进入本机 MT5。
4. 成交后右下角提示「已提交」，前端会自动截一张主图存进交易日志。

### 第 7 步：管理持仓

右侧切到「持仓」标签，每一行可以：

| 操作 | 作用 |
|---|---|
| **止损止盈** | 展开输入框，修改或清除 SL/TP |
| **保本** | 把止损移到开仓价（按「保本偏移」设置补上成本点数），自动避开券商最小止损距离；还没回本或离现价太近时只提示、不改单 |
| **平一半** | 平掉一半仓位；已回本时顺便把止损移到开仓价（含保本偏移），未回本时止损保持原值，并提示剩余最大亏损 |
| **移动止损** | 填距离点数后，网关每 0.4 秒把止损跟着价格往有利方向挪，不会往回走 |
| **分批** | 展开分批止盈编辑器：默认按下一个空闲的 1R/2R… 添加一档（平 50%），可改价、改比例、勾选「平后移保本」或删除；添加后也能直接在图上拖绿色虚线 |
| **平仓** | 点两次确认后平掉该仓位 |
| **全部平仓** | 平掉当前账户全部持仓，点两次确认 |
| **全清** | 先撤销当前品种的全部挂单，再平掉当前品种的持仓，点两次确认；别的品种不动 |

### 第 8 步：平仓后看日志

1. 平仓后打开左侧「交易记录 → 交易列表」。
2. 找到刚才那笔，点开可以看图表截图、盈亏、持仓时长、MFE/MAE 和出场方式。
3. 在「盈亏日历」里能看到当天的净盈亏和交易笔数。

至此，一笔完整的模拟交易已经走完。接下来可以按需要阅读后面的章节。

## 5. 交易台详解

### 5.1 图表

- **周期**：图表左上角切换；每个图表格子可以单独设周期。
- **多图布局**：顶栏「布局」可选单图到 6 图；多图时可同步品种、周期、十字线和可视区间。
- **指标**：图表「指标」里可以加内置指标和「MT 双 EMA」等自定义指标；指标组合会自动保存，重启后恢复。
- **指标模板**：图表左下角「指标模板」可以把当前指标组合存成命名模板，换品种后一键套用。
- **画线工具**：左侧工具栏；常用工具可以点星标收藏，收藏项会浮在图表顶部中间。
- **画线模板**：图表左下角「画线模板」可以保存一条线的样式，再套用到其他同类线。
- **历史数据**：往左滚动会按区间加载更早的 K 线；周末/休市窗口会自动往前找最近有数据的区间。能翻到多早取决于本机 MT5 已下载的历史。

### 5.2 图上的价格线

图上会显示这几类线和小块：

- 草稿入场线、止损线、止盈线
- 挂单价格线
- 持仓的开仓价、SL、TP
- 持仓的分批止盈档位：绿色虚线，右侧小块显示 `50% · 0.5手 · 1R`
- 持仓的红色风险区间和绿色盈利区间，绿色区间里有 1R / 2R… 刻度
- 杠杆足够大时的橙色「强平估算」小块

操作规则：

- 线和小块都可以按住上下拖动；松手后写入草稿，或发送改单/改止损请求。
- 草稿入场价和持仓开仓价只做显示，不能拖动改价。
- 拖动时按住 `Shift` 吸附整数点位。
- 线右端的小块会显示手数和预计金额，例如 `0.44 -99.41 USD`；小块上的 `✕` 可以移除止损、止盈或委托。
- 同一价格附近的多笔持仓/挂单会自动竖直错行，不会叠在一起。

分批止盈的规则：

- 每笔持仓最多 8 档；比例作用于**到价当时的剩余仓位**（例如 1 手、1R 平 50%、2R 平 30%，最后剩约 0.35 手）。
- 档位必须比开仓价更靠近盈利方向，且排在最终止盈之前；最终止盈后来被拖到某档之前时，该档变灰、不再执行。
- 到价后先移保本（若勾选）再平仓；未回本或离现价太近、放不下保本止损时只平仓、不改止损；仓位小到拆不开时标记「已跳过」并在面板保留，不会每 0.4 秒重试。
- 阶梯由网关执行。**App 关闭或网关退出时不会执行**，只有券商侧的 SL/TP 继续生效；只读或停机期间暂停执行，恢复可交易后继续。
- 平掉持仓后计划自动清理；手动部分平仓不会删除计划，剩余比例按新的剩余手数计算。

### 5.3 下单票

| 区域 | 说明 |
|---|---|
| **买入 / 卖出** | 选择方向 |
| **市价 / 限价 / 停损** | 市价按当前报价成交；限价和停损需要在图上或票面给委托价 |
| **手数** | 按券商的 min / max / step 对齐；可以点 `−` / `+` 调整 |
| **风险开仓** | 固定金额或余额 %；配合「自动手数」按止损距离算手数 |
| **止损 / 止盈** | 可以直接输入，也可以拖图上的线 |
| **模板栏** | 显示当前模板与摘要；点开可切换、新建或跳到设置页；「启用」后带入风险比例、止盈和分批计划 |
| **策略标签** | 例如「突破」「回踩」，会写进交易日志，之后可按标签统计 |
| **预览区** | 保证金、风险、盈亏比、点差和警告 |
| **开仓清单** | 启用纪律门禁后出现在确认窗里，见 [9.5](#95-开仓纪律门禁) |

**下单模板怎么用：**

1. 在模板栏选择一个模板（默认模板是 `0.5% 风险 · 2R 止盈 · 1R 移到保本`）。
2. 点「启用」。票面会按模板填入风险比例，已有委托价的草稿保留限价/停损，否则准备一张市价草稿；设好止损后止盈按模板的 R 倍数放置。
3. 启用后模板栏下方出现**计划条**：风险 %、实际金额、止盈价、阶段阶梯。
4. 成交后网关每 0.4 秒检查浮盈，按 R 从小到大执行阶段：先移止损（幂等），再按当时剩余仓位的比例平仓。
5. 手动改风险/手数会显示「已偏离模板」，可一键恢复；手动改止盈不会被抢回，可点「用模板止盈」还原。
6. 挂单也可以带模板：成交后自动把阶段计划登记到实际持仓；撤单、过期或 30 天 TTL 到期会自动清理。

> 只读模式或急停期间阶段暂停执行，计划条显示「阶段已暂停」；恢复可交易后继续。切换品种、切换账户、删除当前模板或按 `Esc` / `B` / `S` 重置草稿会解除启用。

### 5.4 持仓

持仓行显示方向、品种、手数、开仓价、当前价、盈亏和 SL/TP。操作见 [第 4 章第 7 步](#第-7-步管理持仓)。

移动止损：

1. 点「移动止损」。
2. 填距离当前价多少点。
3. 点确认。之后止损只会朝有利方向移动，不会退回。
4. 再点一次「取消移损」停止。

### 5.5 挂单

「挂单」标签列出限价/停损委托，显示方向、手数、类型、委托价、SL/TP。

- 点「撤单」撤销。
- 撤单成功后右下角会弹一个持续 6 秒的「撤销」按钮，点它可以用原参数重新挂单（原分批计划不会随之恢复）。
- 标题栏的「全部撤销」点两次会批量撤掉所有挂单；批量撤销不提供撤销按钮，因为价格可能已经穿过，重挂会变成另一笔委托。
- 挂单价格线也可以在图上拖动改价。

### 5.6 自选

- 最多 10 个品种。
- 每 3 秒刷新点差、买价和当日涨跌幅。
- 有持仓的品种带圆点。
- 点一行即可切到该品种；多图时先点目标格子。

### 5.7 价格告警

1. 点顶栏「告警」打开面板。
2. 选品种、方向上穿/下穿、触发价、备注。
3. 可以设置重复提醒和冷却秒数。
4. 打开面板时默认填入当前十字线价格或买价。
5. 网关每 0.5 秒检查一次报价，越线后通过 WebSocket 广播。

提醒方式：

- 在「设置 → 告警」打开声音和桌面通知。
- 首次使用桌面通知时，浏览器/系统会请求权限。
- 第三方通道（Webhook / Discord / Telegram / 企业微信）在 `gateway/config.json` 的 `alert_channels` 里配置；密钥只留在网关配置文件里，界面只显示通道名。

### 5.8 财经日历

- 点顶栏「日历」打开，面板覆盖在图表右侧，不挤压图表。
- 数据来自 ForexFactory 公开周历，网关后台抓取并缓存 6 小时；断网时沿用旧缓存并提示。
- 默认只看当前品种相关货币的高影响事件；可以切「全部」、关闭「仅高影响」。
- 「图表标注」开关会在主图上按事件时间画竖线，只标注当前可见区间内匹配品种货币的高/中影响事件。

### 5.9 风控与急停

顶部风控胶囊显示：

- 今日盈亏 / 当日亏损上限 / 剩余额度
- 悬停看今日开仓次数、连亏次数
- 状态栏会显示冷却或停机原因

**急停：**

1. 点顶栏「急停」。
2. 再点一次「确认平仓？」。
3. 网关平掉全部仓位、撤销全部挂单并停机，之后所有开仓都被拒绝。
4. 按钮变成「恢复交易」，点一次解除。

停机状态存在 SQLite 里，重启网关或应用仍然保持。急停只拦新开仓，平仓、改单、保本和移动止损不受影响。

### 5.10 多账户

- 在「设置 → MT5 账户」增删改账户；顶部账户菜单快速切换。
- 每个账户可以单独配置风控上限；未覆盖的项继承全局默认。
- 切换账户时，网关会 `shutdown` 后重新连接到目标终端并登录；持仓不会被平掉，但移动止损和自动保本只管理当前账户。
- 同一个 `terminal64.exe` 可以配置多个登录号，切换会改变该终端当前登录的账户；希望多个账户同时在线，请给每个账户配置不同的终端路径。
- 连续 3 次自动登录失败后网关会暂停重试；修改密码或连接信息后会重新尝试。

## 6. 历史复盘

复盘页使用历史行情做模拟交易，**不连接实盘、不写实盘日志**。页面左上角会标明「模拟账户 · 不连实盘」。

### 6.1 新建复盘

1. 左侧点「历史复盘」→「新建复盘」。
2. 选择品种和区间：1 周 / 1 个月 / 3 个月 / 自定义开始和结束时间。
3. 选择默认显示周期。
4. 检查「数据覆盖」：绿色表示本机已有缓存，灰色需要联网补齐；会估算 M1 根数、大小和大致回放时长。
5. 设置初始资金、杠杆和账户货币。
6. （可选）展开「成本与撮合」，设置点差和佣金。
7. 创建后先检查本地缓存，缺的行情再从网关补齐。

### 6.2 回放操作

底部控制条：

| 控件 | 作用 |
|---|---|
| ⟲ | 重新开始 |
| ⏭ | 单步前进一根 M1 |
| ▶ / ⏸ | 播放 / 暂停 |
| `1x` `2x` `5x` `10x` `30x` | 回放速度 |
| 进度带 | 显示游标位置和整体进度 |

顶部显示行情时间、进度和「模拟撮合」标记。右侧可以看持仓、挂单、笔记和统计。

### 6.3 模拟下单

- 右侧下单区支持买入/卖出、市价/限价/停损、手数、止损止盈。
- 市价单在**下一根 M1 开盘**按对手价成交；限价/停损单等价格触发。
- 所有成交都是模拟的，不会发送到券商。
- 复盘不经过开仓纪律门禁。

### 6.4 笔记

回放过程中可以在右侧「笔记」里记下判断和情绪，可以加标签。结束后这些笔记会出现在复盘报告里。

### 6.5 结束与报告

1. 点「结束复盘」，确认后会按最后一根 M1 收盘价平掉模拟持仓。
2. 结束后自动打开复盘报告，包含：
   - 净值变化、已平仓净盈亏、胜率、平均 R、最大回撤、交易笔数
   - 模拟净值曲线、R 分布、按标签统计
   - 交易明细
   - 你写的回放笔记
3. 如果这次复盘来自一笔实盘交易或一条「错过机会」，报告里还会有「实盘 vs 重演」对照：方向/手数、入场、出场、R、MFE/MAE、持仓时长、出场方式。

### 6.6 从实盘交易或错过机会开始复盘

- 交易日志里可以对一笔已平仓交易发起复盘；复盘工作台会提供「参照」面板，并可以「重演」：先把游标推回开仓前一根 M1，再按实盘方向、手数、止损止盈预填下单票。
- 「错过机会」里的记录也可以转成复盘，用当时的行情走一遍计划。

## 7. 交易记录

左侧「交易记录」有两个页签：**交易列表**和**盈亏日历**。

### 7.1 交易列表（交易日志）

- 每次平仓后，网关按 `position_id` 把进出场成交配对成一笔交易。
- 列表列：平仓时间、品种/方向、手数、开→平、盈亏、持仓时长、标签、操作。
- 顶部统计卡显示交易笔数、净盈亏、胜率，统计口径与列表筛选一致。
- 区间切换：7 天 / 30 天 / 90 天 / 1 年 / 全部。
- 筛选：品种、标签、盈利/亏损、待复盘/已复盘。
- 直接点表格里的标签可以修改策略标签。
- 点一行打开交易详情。

### 7.2 复盘一笔交易

交易详情抽屉里可以：

- 看图表截图（成交后自动截取，存本机，≤3MB，不上传）。
- 选择关联的策略，逐条标记规则「遵守 / 违反 / 未评估」。
- 看开仓时的清单勾选情况。
- 给执行打分。
- 填错误标签（如「追单、提前离场、移动止损」）。
- 写复盘笔记。
- 「保存复盘」或「标记已复盘」。

复盘数据会进入策略遵守率、过程评分和盈亏日历。

### 7.3 盈亏日历

- 按月归集净盈亏，点某个格子看当天明细。
- 月度统计：本月净盈亏、交易笔数、本月胜率、累计 R、交易日、最好/最差一天。
- 当天明细：逐笔交易、逐笔复盘入口。
- **当天笔记**：可以选情绪（很差 / 差 / 一般 / 好 / 很好）、填标签、写盘前计划/盘中记录/收盘复盘；自动保存，也可以「立即保存」或「存为模板」。
- **复盘卡片**：把当天复盘导出为 PNG 或单页 PDF。隐私模式开启时不能导出含金额的卡片。
- **AI 复盘**（可选）：在设置里配置自己的 API Key 并启用后，可以生成「当日」或「本周」复盘；生成前可以点「将发送哪些字段」查看具体内容，默认不发送你写的笔记，勾选后才会一起发送。

## 8. 分析

「分析」页有两个页签：

- **报表**：统计报表 + 执行质量，共用 7 天 / 30 天 / 90 天 / 1 年 / 全部区间；
- **复盘**：绩效趋势 + 深度分析，共用 90 / 180 / 365 天区间，两个分区只向后端取一次 `review.trades`。

### 8.1 统计报表

以已平仓交易为准，汇总：

- 净盈亏、交易笔数
- 胜率（胜 / 负笔数）
- 盈亏比（平均盈利 / 平均亏损）
- 期望 / 笔、最好 / 最差一笔
- 平均 R、累计 R、R 回撤、1R 到达率、R 覆盖（可折算 R 的笔数占比）
- 累计盈亏曲线 / 累计 R 曲线切换，以及对应的最大回撤
- 区间概览：毛利 / 毛损、平均持仓、平均盈利 / 亏损、风险来源
- 按品种、按时段（开仓小时）分组表现
- 模板执行统计（来自下单模板的分批止盈计划与执行事件）
- 执行成本

报表里的分组行可以下钻到交易日志，带着相同的筛选和区间。

> 统计口径：盈亏 > 0.005 记胜，< -0.005 记负，中间（含 0 和手续费毛刺）不计入胜负。`journal.stats` 最多统计最近 5000 笔，被截断时页面会提示。

### 8.2 绩效趋势

- 按日、按周看盈亏和稳定性。
- 交易散点图：可以点某一笔查看详情，或直接打开复盘。
- 用来判断「最近变好/变差」是运气还是节奏变化。

### 8.3 深度分析

- 维度：品种、方向、标签、星期、时段、持仓时长。
- 结果筛选：全部 / 只看盈利 / 只看亏损。
- 分组汇总表 + 交叉矩阵（例如「品种 × 时段」「标签 × 星期」）。
- 用来找「哪种组合长期不赚钱」。

### 8.4 执行质量

只统计实际发往 MT5 的下单请求：

- 请求数、成交数、拒单/未知数
- 平均点差
- 平均滑点（正数 = 对你不利）、滑点为不利方向的占比、最大滑点
- 成交延迟 P50 / P90 / 最慢
- 按品种的请求数、拒单数、平均点差/滑点/延迟
- 拒单原因聚合（retcode + 券商原文）
- 「最近请求」逐笔核对请求价、成交价、手数、点差、滑点、延迟和状态

> 滑点只对市价成交有意义；延迟是网关 `order_send` 到拿到回执的时间，不含前端与网络往返。

## 9. 纪律

### 9.1 策略手册

1. 左侧「纪律 → 策略手册」→「新建策略」。
2. 填名称、说明（适用品种、时段、行情环境）和规则（一行一条）。
3. 保存后，策略会出现在复盘和开仓清单里。
4. 每笔交易的复盘可以逐条勾「遵守 / 违反」；页面会统计每条规则和每套策略的遵守率。
5. 不再使用的策略可以归档；历史交易里的勾选会保留。

示例规则：

```text
只做 H1 趋势方向
等价格回到前高附近
止损放在结构低点下方
```

### 9.2 例行清单

- 盘前、盘中、盘后各一组固定动作。
- 第一次使用可以点「生成默认清单」，之后在「管理清单」里增删改和归档。
- 每天打勾；页面显示最近 13 周的完成情况。
- 例行清单与盈亏统计完全独立，**不参与开仓门禁判定**。

### 9.3 错过机会

记录「看到了但没做」的交易：

1. 点「记录一笔」。
2. 填品种、方向、观察时间、计划入场价、止损、目标、关联策略和备注。
3. 保存后会用观察时间之后的 M1 行情计算理论 R。
4. 这里的结果是理论值，不含点差/滑点/手续费，**不进入任何绩效统计**。
5. 可以把它转成复盘，用历史行情走一遍计划。

### 9.4 过程评分

入口：概览页的过程评分卡片，或 `Ctrl/Cmd+K` 搜索「过程评分」。

它只评价「做得好不好」，不预测收益。七个分量：

| 分量 | 权重 | 看什么 |
|---|---|---|
| 期望 R | 25% | 每笔平均 R |
| 胜率 | 15% | 盈利交易占比 |
| 盈亏比 | 15% | 平均盈利 / 平均亏损 |
| R 回撤 | 15% | 以 R 计的回撤 |
| 恢复因子 | 10% | 回撤后的恢复能力 |
| 日集中度 | 10% | 盈亏是否过度集中在少数几天 |
| 规则遵守率 | 10% | 复盘中标记的遵守/违反 |

- 样本门槛 20 笔；不足 20 笔不给总分。
- 某个分量没有样本时会被排除，权重自动重新分配；页面会显示当前参与权重。
- 区间可选 30 / 90 / 365 天。

### 9.5 开仓纪律门禁

「设置 → 开仓纪律」把策略清单变成下单前的一次检查。

| 模式 | 行为 |
|---|---|
| 关闭 | 不弹清单，维持普通下单流程 |
| 二次确认 | 清单未完成时，需要勾选「我已复核清单，仍然下单」才能发送 |
| 强制拦截 | 未评估直接拒绝；存在违反项时需要复核并填写理由 |

可配置项：

- **默认清单**：选择一套策略作为默认开仓清单。
- **强行下单时必须填写理由**：开启后，存在违反或未评估项时，勾选复核还不够，还要写下这次破例的理由，理由会写入审计。
- **账户覆盖**：只对当前账户生效，其他账户继续跟随全局。

门禁只拦新开仓；平仓、改单、保本和移动止损永远不受影响，回放里的模拟下单也不经过它。

## 10. 设置

设置页左侧分区：

| 分区 | 主要用途 |
|---|---|
| **外观** | 主题（浅色 / 白色 / 深色）、强调色 |
| **图表** | 默认布局、多图同步项 |
| **交易模板** | 风险 %、止盈 R、分批止盈阶段、多模板管理 |
| **交易与风控** | 手数与风险上限、实盘开关、账户级覆盖 |
| **开仓纪律** | 门禁模式、默认清单、强行下单理由 |
| **MT5 账户** | 添加、编辑、删除、切换账户和保存密码 |
| **告警** | 声音提示、桌面通知 |
| **数据与备份** | 导出交易数据、整库备份与恢复、本机数据目录 |
| **诊断** | 审计日志查询、立即对账、导出诊断 |
| **Pine 脚本** | 实验功能：本地运行 Pine v5/v6 指标 |
| **AI 复盘** | 自带 Key，默认关闭 |
| **更新** | 版本与手动检查更新 |
| **数据与连接** | 终端状态、账户类型、本机路径和快捷键 |

### 10.1 交易与风控

默认安全值：

| 参数 | 默认 | 说明 |
|---|---|---|
| 单笔最大手数 | 0.5 | 超过直接拒绝 |
| 单笔最大风险 | 1.0% | 按净值计算 |
| 最大持仓数 | 3 | 超过不再开新仓 |
| 当日亏损上限 | 2.0% | 已实现 + 浮动；达到后禁止开新仓，0 = 不限制 |
| 当日最多开仓 | 8 | 0 = 不限制 |
| 连亏冷却次数 | 3 | 连续亏损达到后进入冷却，0 = 不启用 |
| 冷却时长 | 30 分钟 | 冷却期间禁止开仓 |
| 最大点差 | 0 | 0 = 不限制 |

另外还有几道固定闸门，不受这些参数影响：

- 券商最小止损距离（`trade_stops_level`）
- 手数 min / max / step 对齐
- 保证金占用 > 可用保证金 90% 拒绝
- 3 秒内同方向同价格重复请求拦截
- 急停后所有开仓拒绝
- `clientOrderId` 幂等、SQLite 意图记录与重启对账

编辑范围可以切到「当前账户」或「全局默认」。账户级修改只影响当前账户，未覆盖的项显示「用全局」，可以单项恢复或一键「全部跟随全局」。

同一页面下方的「保本偏移」：点差已经包含在开仓价里，这里只按**点数**补偿手续费、隔夜利息和止损滑点，默认 0。填了之后「保本」「平一半」立即使用；分批档位的「移保本」在添加档位时记录该值。

### 10.2 实盘开关

- 位置：「设置 → 交易与风控 → 运行模式 → 实盘开关」。
- 打开后，实盘/美分账户才能从只读切到实盘交易。
- 关闭后，实盘账户会锁在只读，顶部模式按钮不可用。
- 实盘开关等价于 `gateway/config.json` 的 `allow_live: true`，立即生效。

### 10.3 交易模板

- 可以建立多个模板，例如「日内」「波段」。
- 每个模板包含：风险 %、止盈 R 倍数、分批止盈阶段。
- 默认模板：0.5% 风险 + 2R 止盈 + 1R 移到保本。
- 模板存在本机 `mytrade.templates`，不上传。
- 下单票的模板栏可以直接切模板、新建模板或跳到这里编辑。

### 10.4 MT5 账户

- 添加账户时填名称、登录号、服务器、`terminal64.exe` 路径和密码。
- 密码用 DPAPI 加密，保存在 `gateway/data/credentials.json`。
- 保存后点「使用」切换；顶部账户菜单也可快速切换。
- 连续 3 次自动登录失败会暂停重试；修改密码后会重新尝试。
- 删除账户会一并清除本机保存的密码，但不会删除交易日志和历史数据。

### 10.5 告警

- 声音提示、桌面通知两个开关。
- 外部通道在 `gateway/config.json` 的 `alert_channels` 里配置，支持 `webhook` / `discord` / `telegram` / `wecom`。
- 密钥只留在网关配置文件里，前端只显示通道名称。

### 10.6 数据与备份

- **导出**：按 7 / 30 / 90 天或全部，导出交易日志 CSV、执行质量 CSV、审计日志 JSONL、设置 JSON、复盘会话 JSON。
- **整库备份**：把数据库、设置、审计日志和截图打成 zip，存到本机 `backups/`。
- **自动备份**：网关每小时检查一次，24 小时内没有自动备份就生成一份，只保留最近 7 份；手动备份不会被自动清理。
- **恢复**：桌面版里点备份行「恢复」，会先停网关、校验备份里的数据库，再把旧的 `data/`、`audit/` 改名成 `*.old-<时间>` 保留，换上新数据并重启网关；本地 MT5 凭据会保留。
- **导出诊断**：下载一份 JSON 诊断包，包含网关 health、数据库自检、备份列表、日志尾部（敏感字段已脱敏）和前端未捕获异常。

### 10.7 诊断

- 查询审计日志：按 UTC 日期、类型前缀、文本筛选，最多返回 300 条，可展开看完整 payload。
- 「立即对账」：按 `clientOrderId` 与 MT5 挂单、持仓、最近 7 天成交重新对账，显示检查/找到/未找到数量。
- 网关启动时会在后台跑一次 SQLite 完整性检查，结果显示在 `/health` 的 `database` 字段。

### 10.8 Pine 脚本（实验）

- 粘贴原生 Pine v5/v6 indicator 源码，保存后由 PineTS 在本地执行。
- 指标元信息只在图表创建时生成，保存/删除脚本后需要刷新一次图表。
- 行情只来自当前 MT5 网关。
- PineTS 是第三方运行时（AGPL-3.0 / 商业授权），与 TradingView 无关联。

### 10.9 AI 复盘（可选）

- 默认关闭；关闭或没有 Key 时功能完全不可见。
- 使用你自己的 API Key。
- 只发送聚合统计和你在面板里勾选的笔记，不含账户号、服务器、密码、截图。
- 支持「当日」和「本周」两种复盘。

### 10.10 更新

- 桌面版启动约 6 秒后自动检查 GitHub Releases。
- 有新版时右下角提示，可以「立即更新」「稍后」或「忽略此版本」。
- 顶部「更新」按钮可随时手动检查。
- 更新包使用 Tauri 签名校验，签名不匹配不会安装。
- 浏览器开发模式不支持更新，会在「更新」页提示「开发模式」。

## 11. 数据、备份与隐私

### 11.1 只在本机

- 网关只监听 `127.0.0.1`。
- WebSocket 握手、CORS 和截图接口只接受 Vite 开发页与 Tauri 桌面壳的来源；浏览器里的其他网页即使向本机发起连接也会被拒绝。
- 交易数据、截图、审计日志、导出和备份都只在本机。
- MT5 密码用 Windows DPAPI 加密，只有当前 Windows 用户能解密。

### 11.2 备份建议

| 时机 | 动作 |
|---|---|
| 首次配置完成后 | 创建一次手动备份 |
| 每周 | 检查自动备份是否在生成 |
| 升级 / 重装 / 换机前 | 手动创建备份，并把 `backups/` 复制到其他磁盘 |
| 恢复前 | 确认备份时间，恢复会保留旧目录为 `*.old-<时间>` |

备份不包含 `config.json` 和 MT5 登录凭据；换机后重新登录账户即可。

### 11.3 隐私模式

- 左侧底部开关。
- 打开后，复盘与报表页的金额显示为 `••••`；交易台不受影响。
- 隐私模式下不能导出含金额的复盘卡片。

## 12. 常见问题

### 界面一直显示「等待 MT5 终端」

1. 确认 MT5 已启动并登录账户。
2. 确认 `MetaTrader5` 包版本与终端匹配。
3. 打开 `http://127.0.0.1:8765/health` 看 `lastError`。
4. 如果在设置里保存了密码，检查登录号、服务器和终端路径。

### 保存密码后仍提示自动登录失败

- 服务器名必须和 MT5 登录窗口完全一致。
- 密码正确，`terminal_path` 指向实际使用的 `terminal64.exe`。
- 连续 3 次失败后网关会暂停重试；修改该账户密码或连接信息后会自动重新尝试。
- 失败记录可在「审计日志」里搜索 `account.login_failed`，不会记录密码。

### 提示「MT5 未开启 Algo Trading」

在 MT5 顶部工具栏点击「算法交易 / Algo Trading」，图标变绿即可。

### 下单被拒：STOPS_LEVEL

止损/止盈距离小于券商最小点数。把 SL/TP 拖远一点，网关会提示具体点数。

### 下单被拒：RET_10030 / INVALID_FILL

券商的成交填充模式不支持。网关会按 `symbol_info.filling_mode` 自动选择 IOC / FOK / RETURN；若仍失败，请把该品种信息反馈给开发者。

### 连到了另一个 MT5 终端的账户

电脑上同时开着多个 MT5 时，不指定路径可能连到最近用过的那个。在账户里把 `terminal_path` 设成目标终端 `terminal64.exe` 的完整路径，重启网关。

### 图表空白 / 提示「Charting Library 未加载」

`public/charting_library/` 是 TradingView 官方库，已 gitignore、不进仓库。换机器或重新克隆时，把整个目录复制到 `public/charting_library/`（保留 `bundles/` 和 `charting_library.standalone.js`），再刷新页面。

### 图表时间和 MT5 不一致

图表把「券商服务器时间」整体当成 UTC 显示，网关同时下发 `serverOffset`，所以图上的时间、日线分组和 MT5 终端一致。底部时钟显示的是服务器时间。

### 价格显示成很长的小数

拖动时已按 tick 对齐；手动输入框保留原始输入，发送前网关会再次对齐。

### 点「更新」提示检查失败

- 确认 GitHub 上已有 release，并且 release 里上传了 `latest.json`。
- 网络需要能访问 `github.com`；公司代理或离线环境会检查失败。

### 操作超时 / 提示「结果未知」

网关给每条命令设了超时。行情、统计、AI 复盘、导出/备份等长命令 18–85 秒；前端超时始终比服务端多留几秒。

- 只读命令超时返回 `TIMEOUT`，可以安全重试。
- 可能已经改变券商状态的命令（下单、改单、撤单、改止损、保本、平仓）超时返回 `RESULT_UNKNOWN`：网关不会误报失败，而是在工作线程恢复空闲后自动对账。界面提示稍后核对持仓与挂单，也可以到「设置 → 诊断 → 立即对账」手动触发。

### 实盘模式切不过去

需要同时满足：

1. 「设置 → 交易与风控」的实盘开关已打开。
2. MT5 的 Algo Trading 已打开。
3. 账户是实盘（美分账户也属于实盘）。
4. 前端手动切到实盘。

### 重装后数据还在吗

数据在 `%LOCALAPPDATA%\MyTrade\gateway\`，卸载/重装应用一般不会删除。重装或换机前建议先创建备份。

## 13. 实盘前检查清单

> 强烈建议：先在模拟账户完整走一遍「开仓 → 拖止损 → 平仓 → 重启应用恢复状态」，再考虑实盘。

### 13.1 四个条件

- [ ] 「设置 → 交易与风控 → 实盘开关」已打开
- [ ] MT5 的 Algo Trading 已打开
- [ ] 账户本身是实盘（美分账户也属于实盘）
- [ ] 前端已手动切到「实盘交易」

### 13.2 下单前

- [ ] 确认当前账户是预期账户（顶部账户菜单）
- [ ] 确认当前品种和周期
- [ ] 确认止损已设置，且距离大于券商最小止损距离
- [ ] 确认风险金额和风险 % 在可接受范围
- [ ] 确认保证金占用不超过可用保证金
- [ ] 确认没有触发当日亏损上限、连亏冷却、开仓次数上限或急停
- [ ] 确认策略标签已填（方便之后统计）
- [ ] 如果有开仓清单，逐条评估

### 13.3 下单后

- [ ] 检查持仓是否出现在「持仓」标签
- [ ] 检查 SL/TP 是否正确
- [ ] 检查交易日志是否在平仓后自动生成
- [ ] 检查执行质量页的滑点和延迟是否正常
- [ ] 当天结束后写盈亏日历笔记并逐笔复盘

### 13.4 出现异常时

- 需要立刻停止交易：点两次「急停」。
- 需要核对订单：打开「设置 → 诊断 → 立即对账」。
- 需要反馈问题：先「导出诊断」，再说明复现步骤。

## 14. 附录

### 14.1 快捷键速查

| 按键 | 作用 |
|---|---|
| `B` | 买入市价草稿 |
| `S` | 卖出市价草稿 |
| `Esc` | 关闭弹窗 / 取消确认 / 清除划线草稿 |
| `Ctrl/Cmd+K` | 命令面板 |
| `Shift` + 拖动 | 价格吸附整数点位 |
| `↑` `↓` `Enter` | 命令面板内选择和执行 |

### 14.2 术语表

| 术语 | 含义 |
|---|---|
| **点（point）** | 券商报价的最小变动单位；FX 通常 0.00001，黄金 0.1 |
| **点差** | 买价与卖价的差，交易成本的一部分 |
| **滑点** | 实际成交价与请求价的差；正数表示对你不利 |
| **手数（lot）** | 交易数量单位，按券商的 min / max / step 对齐 |
| **保证金** | 开仓需要占用的资金 |
| **止损 / 止盈** | 自动平仓的价格；止损限制亏损，止盈锁定盈利 |
| **限价单** | 在指定价格或更好价格成交的挂单 |
| **停损单** | 价格突破指定价位后触发的挂单 |
| **R** | 以初始止损距离为 1 个风险单位；盈利 2R 表示赚了 2 倍初始风险 |
| **MFE / MAE** | 持仓期间的最大有利波动 / 最大不利波动 |
| **回撤** | 从净值高点到低点的下降幅度 |
| **盈亏比** | 平均盈利 / 平均亏损 |
| **期望** | 每笔交易的平均盈亏 |
| **余额 / 净值** | 余额是已实现资金；净值是余额加上浮动盈亏 |
| **强平** | 保证金不足时券商强制平仓 |

### 14.3 推荐使用节奏

**盘前**

1. 打开 MT5 和 Tally，确认连接。
2. 看「概览」的例行清单和开仓门禁状态。
3. 看财经日历，标记当天高影响事件。
4. 在自选里确认要做的品种。

**盘中**

1. 在交易台看图，用画线下单。
2. 下单前过一遍风控胶囊和开仓清单。
3. 成交后用保本、移动止损、平一半管理仓位。
4. 需要离开时设置价格告警。

**盘后**

1. 到「交易记录」逐笔复盘，勾规则、打分、写笔记。
2. 在「盈亏日历」写当天总结，导出复盘卡片。
3. 看「分析 → 报表」确认统计与执行质量没有异常。

**周末**

1. 看「分析 → 复盘」，找长期不赚钱的组合。
2. 更新策略手册和例行清单。
3. 检查「设置 → 数据与备份」是否已生成自动备份。
4. 需要时创建一次手动备份。
