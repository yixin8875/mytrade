## 1. 现状问题

当前交易台的骨架（`src/App.tsx` + `ConsoleShell.tsx`）：

```
┌────────────┬──────────────────────────────────────┬───────────────┐
│ 应用侧栏    │ TopBar：布局/报价/告警/账户/风控/急停   │ 下单表单       │
│ 240px      ├──────────────────────────────────────┤ 336px（很长）  │
│ 账户余额    │                                      ├───────────────┤
│ 导航       │            ChartGrid                 │ 持仓/挂单/自选 │
│            │                                      │ 三个窄标签页    │
├────────────┴──────────────────────────────────────┴───────────────┤
│ StatusBar：连接/终端/账户/风控/延迟/版本（无资金指标）                │
└──────────────────────────────────────────────────────────────────┘
```

具体问题：

1. **下单表单和三个列表挤在同一个 336px 窄栏里**：下单表单本身有方向、类型、模板、风险、手数、价格、止损止盈、预览、开仓清单等十余个区块，占满后持仓/挂单只能分到 200–240px 的滚动区，看不到完整表格。
2. **顶栏信息过载**：布局、Bid/Ask/点差、告警、日历、账户切换、余额、净值、风控、急停、模式、连接状态全部挤在 48px 里，账户和风控信息与图表争空间。
3. **没有底部订单区**：Exness 的“未结订单 / 挂单 / 已平仓”是一整块横向表格，能同时看到品种、方向、手数、开仓价、现价、SL/TP、盈亏和操作；我们只能在窄栏里竖排卡片。
4. **品种切换路径长**：要切品种得用图表自带的品种弹窗或右侧自选标签，没有 Exness 顶部那种“多品种标签 + 关闭”的工作区概念。
5. **应用侧栏 240px 在交易时只承担导航**：Exness 用 40px 图标栏 + 独立自选列表列，把纵向空间留给行情和订单。
6. **资金指标位置不对**：余额/净值在顶栏，保证金、可用保证金、保证金比例完全没有常驻展示；Exness 全部收在底部状态栏。
7. **自选没有行情表**：现在是一行一个品种的卡片，只有点差和涨幅，没有 Exness 的“品种 / 卖价 / 买价”列，扫一眼报价的效率低。

## 4. 各区域规格

### 4.1 顶栏（`TopBar.tsx`）

从左到右：

1. 布局选择器（现有 `LayoutPickerButton`，不变）。
2. 分隔线。
3. **品种标签条**（新 `SymbolTabs`）：
   - 标签 = 工作区最近打开的品种，默认取自选前 3 个；持久化 `mytrade.openSymbols`。
   - 标签显示去掉券商后缀的短名（`XAUUSDc` → `XAUUSD`），有持仓时名字左侧一个圆点。
   - 点击标签 = 切到“当前激活图表格”的品种（复用 `chart/tv/registry` 的 `requestSymbol`），多图布局下只影响当前格。
   - `✕` 从标签条移除（不删自选、不平仓）；`+` 打开品种搜索下拉（支持代码/描述模糊搜索），选中后加入标签并切图。
   - 标签条横向滚动，不换行。
4. 右侧（靠右排布）：告警、日历、账户切换器、余额（账户货币）、交易模式按钮、急停、连接点。
   - 移除 Bid/Ask/点差（报价已在下单面板头部和图表图例里）。
   - 移除净值（进状态栏）。

### 4.2 导航栏（`ConsoleShell.tsx`）

- `page === 'trade'` 时渲染 56px 图标栏：Logo 标记、概览/交易台/历史复盘/交易记录/分析/纪律、隐私、设置、检查更新。
- 每个按钮保留 `aria-label`/`title`，现有测试的 accessible name 不变。
- 图标栏底部一个“钉住”按钮：钉住后展开成现在的 240px 侧栏（覆盖在图表上，不挤压），刷新后记住。
- 其它页面维持 240px 原样，不动。
- 账户余额块从侧栏移除（已迁到顶栏和状态栏）。

### 4.3 自选列（重做 `WatchlistPanel.tsx`）

品种              卖价      买价     涨跌

- 列宽：品种 1fr，卖价/买价各 64px，涨跌 52px，11px 等宽数字。
- 行高 32px，单行；名称过长省略，`title` 显示全名。
- 点击行 = 切换当前激活图表品种并加入标签条。
- 悬停行尾出现 `✕` 移除自选。
- 过滤：全部 / 持仓中 / 有挂单；搜索按代码/描述过滤。
- 空状态、未连接状态沿用现有文案。
- 数据复用现有 `watchlist.get` 每 3 秒轮询，不新增网关方法。

### 4.4 下单面板（`OrderTicket.tsx`）

保留全部业务逻辑（模板、风险换算、开仓清单、确认弹窗、快捷键 B/S），只重排视觉：

1. **头部**：品种全名 + 描述；右侧是**下单模式菜单**（`常规模式 ▾`）和收起面板的 `✕`；下面两行大号报价：卖价（红）/ 买价（绿），中间列点差（点）。
2. **买卖按钮**：并排两块，各占一半、高 56px，实心红/绿，标签“卖出/买入”，下面小一号价格。常规模式下按下即开一张**市价草稿**（图上出现跟随现价的委托线），边框高亮，底部主按钮变成“确认卖出 0.05 手”。
3. **市价 / 挂单**：两个页签。挂单只填委托价，**限价 / 停损由方向 + 价格相对市价的高低自动推导**（见 4.4.3）。
4. 中段内容随**下单模式**切换，见 4.4.1。
5. 开仓清单/纪律门禁：放在确认弹窗里完整展示（现在就是这么做的），面板上只留一个徽标“清单 4/5”。

> 下单流程（常规/风险模式）不变：选方向 → 调手数/止损 → 点主按钮 → 弹窗确认 → 发送。

#### 4.4.1 下单模式（新增）

标题行右侧的菜单，三项，当前项打勾，切换后立即生效并持久化：

| 模式 | 中段界面 | 提交行为 | 适用 |
|---|---|---|---|
| **常规模式**（默认） | 交易量步进器 + 止损/止盈两行 + 「仓位与风险」「成本与保证金」折叠区 | 点主按钮 → 确认弹窗 → 发送 | 全部账户 |
| **单击模式** | 同上，但去掉主按钮；买卖按钮下方常驻红色提示条“单击模式：点击即按市价下单，不弹确认”；按钮文字变为“单击卖出 / 单击买入” | 点击买/卖按钮立即 `order.place`（市价），跳过方向选择与确认弹窗 | 只读模式不可选；实盘需额外确认 |
| **风险计算表格** | 手数输入整体替换为表格：`固定金额 / 余额 %` 分段 + 风险金额步进器（显示可用余额）、止损价（100/300/500 点快捷，显示距现价点数）、止盈价（1R/2R/3R 快捷，显示 R:R）、只读行「自动手数 / 风险占比 / 保证金 / R:R」，限额与警告原样展示；未填止损前底部按钮为「设定止损与风险值」并禁用 | 计算完成后仍走确认弹窗 | 全部账户 |

**与现有能力的对应关系**

- 风险计算表格就是现有 `trade.size` / `trade.preview` + `patchRisk` 的逻辑，从“藏在折叠区”提升为独立模式；模板的 `riskPercent`、止盈 R 倍数直接填入。
- 单击模式复用现有 `handlePlace` → `send` 的快捷路径，只是不发 `setConfirm(true)`；订单仍带 `clientOrderId`、审计、风控校验和成交截图。
- 常规模式 = 现在的完整表单，默认选中。

**单击模式的安全约束（本方案新增，必须实现）**

1. 只读模式下菜单项禁用，并提示“先切到模拟/实盘可交易”。
2. 必须已设置止损。下单模板只提供风险比例与止盈，不含止损，**不能替代手动止损**；未设止损时买卖按钮禁用并提示“单击模式要求先设置止损”。
3. 实盘账户：开启前弹一次确认“单击模式会跳过确认弹窗”；**每次启动应用都重置回常规模式**，不在实盘上持久化。
4. 单击模式下主区域顶部常驻红色提示条，面板边框变为方向色，避免忘记当前模式。
5. 同一秒内重复点击只接受第一笔（沿用网关 3 秒重复下单拦截，前端再加 800ms 防抖）。
6. 模式切换写入审计（`audit` 或本地事件日志），复盘时可查“这笔是单击下的”。

> 如果你希望单击模式只对模拟盘开放、实盘永远不允许，这个开关在设置里加一行即可；本方案默认“实盘可用但每次启动重置 + 二次确认”。

#### 4.4.2 下单模板与止损/止盈的落位

**模板与这次布局改造没有耦合**，只换位置，不改行为：

- 在类型分段下方放一条紧凑模板行（默认 34px）：
  ```
  [零亏模板]  2% 风险 · 2R 止盈 · 3 段分批 · 1R 保本     已启用  [编辑]
  ```
  - 未启用时显示“选择模板…”，点开现有模板下拉；启用后整行用 accent 底色。
  - 摘要沿用 `templateSummary()` / `templateStepsSummary()`，不新写文案。
  - 「编辑」仍打开现有 `TemplateEditor`；设置页里的模板管理入口不变。
- 模板内容不变：风险占比、按 R 的最终止盈、分批止盈阶段、启用/停用、偏离提示（`riskDeviated` / `tpManual`）。
- 与三种模式的关系：

| 模式 | 模板提供什么 | 模板不提供什么 |
|---|---|---|
| 常规 | 风险占比 → 手数，止盈 R → 止盈价，成交后分批计划 | 止损价（始终手动） |
| 风险计算表格 | 风险占比、止盈 R 预填到表格，可手改，改后标记“已偏离模板” | 止损价（表格里必须填） |
| 单击模式 | 风险占比 → 手数，止盈 R → 止盈价 | 止损价；**没有止损就不能单击** |

**止损/止盈控件（面板内样式）**：

```
止损   100点 · 300点 · 500点   [ 未设置          ]  ✕
止盈   1R · 2R · 3R            [ 未设置          ]  ✕
```

- 未设置时灰字；设置后显示价格，右侧出现 `✕` 清除。
- 止损快捷值按当前价偏移固定点数（100/300/500 点，按品种 `point` 换算）；**新开仓没有“保本”止损**，保本只出现在已有持仓的托盘操作里。
- 止盈快捷值按已设止损的 R 距离计算；未设止损时提示先设止损。
- 图上拖动止损/止盈，结果回填到这两行（沿用现有 `position.modify` / `order.modify`）。

**图上样式（2026-11-20 二次对齐 Exness）**：

- 市价草稿：一条**跟随现价的虚线**（卖出贴 Bid、买入贴 Ask），右缘标签 `[TP][SL] 0.05 ≈-0.05 USD ✕`；TP/SL 小徽标表示保护单是否已设置（未设置时半透明），金额是按当前价平仓的点差成本。
- 止损 / 止盈：右缘是「`SL` / `TP` 徽标 + 价格 + 金额 + ✕」组合块，止损红、止盈绿。
- 未设置止损/止盈时**不画引导线**；`TP` / `SL` 徽标本身就是拖拽手柄：按住向上/向下拉，覆盖层出现跟随指针的虚线 + 价格小块，松手才写入草稿（只点一下不生成）。生成后继续拖标签或线调整，拖线时对应盈亏区域加深。
- 区间：入场→止损铺淡红、入场→止盈铺淡绿；**拖动止损/止盈时对应区间加深**（拖右缘标签或直接拖图上的线都生效，由 `priceLines` 上报拖动状态）。
- 挂单：右缘标签 `限价买入 0.05 @ 1980.00 ✕`；价格落在点差内时变琥珀色并显示「待定价」，主按钮禁用。
- 实现：`ChartPanel` 组合 `ChartChips`（覆盖线 / 徽标 / 区间）与 `PriceLineLayer`（可拖价格线），不新增依赖。

#### 4.4.3 常规模式：市价线与挂单推导（2026-11-20 追加）

| 操作 | 结果 |
|---|---|
| 点卖出 / 买入 | `draft = { active, side, type: 'market', price: 对手价 }`，图上立刻出现市价虚线，面板出现手数与止损/止盈 |
| 切到「挂单」 | 默认价放在市价外 10 tick，只填价格；类型自动推导 |
| 买入 · 价格低于 Ask | 限价买入（等回落） |
| 买入 · 价格高于 Ask | 停损买入（追突破） |
| 卖出 · 价格高于 Bid | 限价卖出（等反弹） |
| 卖出 · 价格低于 Bid | 停损卖出（追空） |
| 价格落在点差内 | 「待定价」，主按钮禁用，图上标签变琥珀色 |
| 手数 | 模板启用且风险为自动时由 `trade.size` 按止损距离反算，徽标「模板自动」；手动改手数变「手动」 |

## 8. 验收标准

1. 1920×1080 下：顶栏一排即可完成切品种、看告警/日历、切账户、切模式/急停。

7. 浅色/深色主题、单图/多图布局、图表拖线改价均不受影响。
